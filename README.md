<a id="tips"></a>

## Prompt Writing Tips

1. **Subject first**: say clearly what the image is about, then add details.
2. **Name the medium**: photo, watercolor, 3D render, ukiyo-e, poster…
3. **Describe the light**: golden hour, Rembrandt lighting, neon, overcast.
4. **Add camera terms** for photos: lens (35mm, 85mm), aperture (f/1.4), angle.
5. **Put text in quotes**: models render `"JAZZ NIGHTS"` far more accurately than unquoted text.
