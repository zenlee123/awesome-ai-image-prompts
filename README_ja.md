## API で生成する

プレビュー画像はすべて [RouterBase](https://routerbase.com) で生成しました。OpenAI 互換の API ひとつで Nano Banana、GPT Image、Gemini、Seedream などを利用できます：

```bash
curl https://routerbase.com/v1/images/generations \
  -H "Authorization: Bearer $ROUTERBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "google/gemini-nano-banana-2.1-t2i", "prompt": "…", "aspect_ratio": "16:9"}'
```

<a id="tips"></a>

## プロンプト作成のコツ

1. **主題を最初に**：何を描くかをはっきり書いてから詳細を足す。
2. **表現手法を指定**：写真、水彩、3D レンダリング、浮世絵、ポスターなど。
3. **光を描写する**：ゴールデンアワー、レンブラントライティング、ネオン、曇天。
4. **写真ならカメラ用語を**：レンズ（35mm、85mm）、絞り（f/1.4）、アングル。
5. **文字は引用符で囲む**：`"JAZZ NIGHTS"` のように書くと文字の描画精度が大きく上がります。

PR 歓迎です！`prompts.json` にエントリーを追加し（8 言語すべて、または分かる言語だけで OK）、`python3 scripts/generate.py` と `python3 scripts/build_readme.py` を実行してください。
