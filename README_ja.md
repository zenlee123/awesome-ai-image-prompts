<a id="tips"></a>

## プロンプト作成のコツ

1. **主題を最初に**：何を描くかをはっきり書いてから詳細を足す。
2. **表現手法を指定**：写真、水彩、3D レンダリング、浮世絵、ポスターなど。
3. **光を描写する**：ゴールデンアワー、レンブラントライティング、ネオン、曇天。
4. **写真ならカメラ用語を**：レンズ（35mm、85mm）、絞り（f/1.4）、アングル。
5. **文字は引用符で囲む**：`"JAZZ NIGHTS"` のように書くと文字の描画精度が大きく上がります。
