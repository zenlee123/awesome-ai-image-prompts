## API로 생성하기

모든 미리보기 이미지는 [RouterBase](https://routerbase.com)로 생성했습니다. OpenAI 호환 API 하나로 Nano Banana, GPT Image, Gemini, Seedream 등을 사용할 수 있습니다:

```bash
curl https://routerbase.com/v1/images/generations \
  -H "Authorization: Bearer $ROUTERBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "google/gemini-nano-banana-2.1-t2i", "prompt": "…", "aspect_ratio": "16:9"}'
```

<a id="tips"></a>

## 프롬프트 작성 팁

1. **주제를 먼저**: 무엇을 그릴지 분명히 쓴 뒤 세부 사항을 더하세요.
2. **표현 방식을 지정**: 사진, 수채화, 3D 렌더링, 우키요에, 포스터 등.
3. **빛을 묘사**: 골든아워, 렘브란트 조명, 네온, 흐린 날.
4. **사진에는 카메라 용어를**: 렌즈(35mm, 85mm), 조리개(f/1.4), 앵글.
5. **텍스트는 따옴표로**: `"JAZZ NIGHTS"`처럼 쓰면 글자를 훨씬 정확하게 그립니다.
