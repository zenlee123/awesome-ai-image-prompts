Tous les aperçus ont été générés avec [RouterBase](https://routerbase.com), une API compatible OpenAI pour Nano Banana, GPT Image, Gemini, Seedream et plus encore :

```bash

  -H "Authorization: Bearer $ROUTERBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "google/gemini-nano-banana-2.1-t2i", "prompt": "…", "aspect_ratio": "16:9"}'
```

<a id="tips"></a>

## Conseils de rédaction

1. **Le sujet d'abord** : dites clairement ce que montre l'image, puis ajoutez les détails.
2. **Nommez la technique** : photo, aquarelle, rendu 3D, ukiyo-e, affiche…
3. **Décrivez la lumière** : heure dorée, éclairage Rembrandt, néon, ciel couvert.
4. **Ajoutez des termes photo** : objectif (35 mm, 85 mm), ouverture (f/1,4), angle.
5. **Mettez le texte entre guillemets** : les modèles rendent `"JAZZ NIGHTS"` bien plus fidèlement.
