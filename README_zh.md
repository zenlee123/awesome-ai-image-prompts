<a id="tips"></a>

## 提示词写作技巧

1. **主体先行**：先说清楚画面主体是什么，再补充细节。
2. **指明媒介**：照片、水彩、3D 渲染、浮世绘、海报……
3. **描述光线**：黄金时刻、伦勃朗光、霓虹、阴天柔光。
4. **照片加入相机参数**：焦段（35mm、85mm）、光圈（f/1.4）、拍摄角度。
5. **文字放进引号**：写成 `"JAZZ NIGHTS"`，模型渲染文字会准确得多。
