Jeder Prompt wurde auf einem echten Modell ausgeführt, das Ergebnis steht direkt daneben. Kopiere den Prompt in deiner Sprache und füge ihn in Nano Banana, GPT Image, Gemini, Midjourney, Seedream, Flux oder einen anderen Bildgenerator ein.

> Die Vorschaubilder wurden mit dem englischen Prompt erzeugt. Moderne mehrsprachige Modelle liefern mit den übersetzten Prompts sehr ähnliche Ergebnisse.

## Per API generieren

Alle Vorschauen wurden mit [RouterBase](https://routerbase.com) erzeugt, einer OpenAI-kompatiblen API für Nano Banana, GPT Image, Gemini, Seedream und mehr:

```bash
curl https://routerbase.com/v1/images/generations \
  -H "Authorization: Bearer $ROUTERBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "google/gemini-nano-banana-2.1-t2i", "prompt": "…", "aspect_ratio": "16:9"}'
```

<a id="tips"></a>

## Tipps zum Prompt-Schreiben

1. **Motiv zuerst**: sag klar, worum es im Bild geht, dann folgen die Details.
2. **Nenne das Medium**: Foto, Aquarell, 3D-Rendering, Ukiyo-e, Poster…
3. **Beschreibe das Licht**: goldene Stunde, Rembrandt-Licht, Neon, bedeckter Himmel.
4. **Kamerabegriffe für Fotos**: Objektiv (35 mm, 85 mm), Blende (f/1,4), Perspektive.
5. **Text in Anführungszeichen**: `"JAZZ NIGHTS"` wird von Modellen deutlich genauer dargestellt.
