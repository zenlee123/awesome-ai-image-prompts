```bash

  -H "Authorization: Bearer $ROUTERBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "google/gemini-nano-banana-2.1-t2i", "prompt": "…", "aspect_ratio": "16:9"}'
```

<a id="tips"></a>

## Consejos para escribir prompts

1. **El sujeto primero**: di claramente qué muestra la imagen y luego añade detalles.
2. **Nombra la técnica**: foto, acuarela, render 3D, ukiyo-e, póster…
3. **Describe la luz**: hora dorada, iluminación Rembrandt, neón, día nublado.
4. **Usa términos de cámara** en fotos: objetivo (35 mm, 85 mm), apertura (f/1.4), ángulo.
5. **Pon el texto entre comillas**: los modelos dibujan `"JAZZ NIGHTS"` con mucha más precisión.
